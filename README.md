# Maria Parache - Portfolio

This is my personal portfolio website, created to showcase my background, technical skills, projects, and interests.

The site includes:

- A responsive homepage with links to my GitHub, LinkedIn, and resume
- An About Me section with an interactive image carousel
- A Projects section featuring projects I have worked on, including QuizApp and InternPing
- Direct links to GitHub repositories for each featured project
- A responsive design optimized for desktop, tablet, and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub Pages

## Features

- Responsive navigation menu
- Smooth scrolling between sections
- Interactive image carousel
- Project cards with descriptions and technology tags
- GitHub repository links for featured projects
- Downloadable resume
- Responsive layout for different screen sizes

## Projects Featured

### QuizApp
A full-stack trivia application built collaboratively with a team. I focused on the frontend interface using HTML and CSS while working alongside teammates responsible for JavaScript functionality and the Node.js, Express, and MongoDB backend.

### InternPing
An internship discovery platform created during Hack Knight. I contributed to the UI/UX design, wireframing, branding, and frontend development.

### Personal Portfolio
This website was designed and developed from scratch to showcase my projects, experience, skills, and interests in a clean and user-friendly format.

## Live Website

The portfolio is hosted using GitHub Pages.
